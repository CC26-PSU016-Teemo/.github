# TEEMO - CC26-PSU016 - Coding Camp 2026 powered by DBS Foundation

## Apa itu TEEMO?

TEEMO adalah platform berbasis web yang dirancang untuk membantu pengguna menemukan informasi kompetisi, hackathon, dan proyek kolaboratif yang relevan, sekaligus memfasilitasi pembentukan tim secara lebih terarah dan berbasis data.

Di era digital saat ini, pengembangan karier dan portofolio melalui kompetisi, hackathon, maupun proyek kolaboratif menjadi semakin penting bagi talenta muda. Namun, informasi mengenai event tersebut masih sering tersebar di berbagai grup komunitas, media sosial, dan platform lain secara tidak terstruktur. Hal ini membuat calon peserta membutuhkan waktu lebih lama untuk mencari event yang sesuai serta kesulitan menemukan rekan tim yang memiliki visi, komitmen, dan keahlian yang selaras.

TEEMO hadir sebagai solusi untuk mengatasi fragmentasi informasi dan hambatan kolaborasi tersebut. Platform ini menyediakan portal event terkurasi yang dilengkapi fitur Rooms untuk mendukung diskusi, pencarian anggota tim, dan pembentukan kolaborasi. Dengan menerapkan sistem rekomendasi berbasis collaborative filtering, TEEMO dapat memberikan rekomendasi event dan tim yang dipersonalisasi berdasarkan preferensi serta pola interaksi pengguna.
